Open datasets on the microdrama industry. A GitHub Action copies them from the live [Microdrama Index](https://myshortee.com/research) every day, so the [commit history](https://github.com/Shortee-Inc/research/commits/main/data) is the full history.

| File | What it is | Source | Updated |
|---|---|---|---|
| [instagram_followers.csv](https://github.com/Shortee-Inc/research/blob/main/data/instagram_followers.csv) | Instagram followers of the largest microdrama apps' official accounts, one row per app per day | Meta Instagram Business Discovery API | daily |
| [market_figures.json](https://github.com/Shortee-Inc/research/blob/main/data/market_figures.json) | Market figures quoted word for word, with source URL and the date checked | published research | when sources change |
| [news.json](https://github.com/Shortee-Inc/research/blob/main/data/news.json) | Microdrama headlines with publisher, date and link | Google News search | daily |

How each dataset is collected is on the [methodology]({{ site.baseurl }}/methodology/) page. To cite the data, use [CITATION.cff](https://github.com/Shortee-Inc/research/blob/main/CITATION.cff).
